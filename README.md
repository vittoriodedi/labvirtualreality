# labvirtualreality

This repository contains my final project for the *Laboratorio Realtà Virtuale* course.

## Overview

The goal of the course was to recreate a virtual environment by faithfully modeling and rendering a reference image using **Blender** and **Unity**. The project focused on 3D modeling, scene composition, lighting, and real-time rendering techniques.

## Contents

* 📄 **`progetto iniziale.png`** – The reference image provided by the professor. The entire 3D environment was built based on this visual target.

* 📄 **`stanza.blend`** – Blender file containing all the **3D models of the room**, including furniture and materials. This was the base scene exported to Unity for real-time visualization.

* 📄 **`Progetto Lab. Realtà Virtuale e Aumentata.pdf`** – Final presentation documenting the **entire development process**. It covers:

  * Analysis of the reference image
  * 3D modeling workflow in Blender
  * Export and setup in Unity
  * Challenges encountered and how they were solved
  * Screenshots of the final rendered scene

## Purpose

This repository showcases the hands-on experience acquired during the *Laboratorio Realtà Virtuale* course, emphasizing practical skills in 3D asset creation, scene layout, and cross-platform integration between Blender and Unity.
